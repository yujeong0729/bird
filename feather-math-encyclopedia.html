01 일정한 비율로 퍼지는 깃털 구조 (Rachis & Barb) BRANCHING
∑수학 공식
L(n) = L₀ · φ⁻ⁿ
θ(n) = β·(1−e^{−αn})
φ = 1.6180339...
L₀깃축 기준 길이
φ황금비
β최대 분기각
α각도 수렴 속도
◈패턴 시각화
◎효과 및 응용
경량 고강도 구조 φ⁻ⁿ 비율로 줄어드는 barb = 재료 최소화하면서 면적 최대화. 단위 질량당 강성 최적.
✈️ 드론 프레임 설계
표면적 극대화 n단계 분기 시 표면적 ∝ φⁿ 증가. 같은 부피에서 최대 접촉면.
🫁 인공 폐 필터 구조
02 점점 잦아드는 물결 모양 깃 (Barb Curvature) WAVE
∑수학 공식
y(x) = A·sin(ωx)·e^{−γx}
ω = 2π/λ
A: 진폭, γ: 감쇠계수
Abarb 곡률 진폭
ω반복 주파수
γ감쇠 속도
λ파장 (간격)
◈패턴 시각화
◎효과 및 응용
올빼미 무음 비행 γ 큰 앞날개 빗살 = 湍流 와류를 조기 소멸. 소음 주파수 4kHz 이상 30dB 감쇠.
✈️ 항공기 날개 leading edge
충격 흡수 감쇠파 구조 = 에너지를 열로 점진 변환. 헬멧·신발 충격재.
🏃 스포츠 쿠셔닝 소재
03 빛의 반사로 색이 만들어지는 구조 (Thin-Film / 구조색) OPTICS

🌈 위조방지 홀로그램

◈패턴 시각화
◎효과 및 응용

🌡️ 에어로겔 대체 단열재
안테나 소형화 프랙탈 안테나: 같은 D 구조 = 파장보다 훨씬 작은 크기로 광대역 수신.
📡 스마트폰 내장 안테나

① 황금비 분기 구조 알고리즘
// L(n) = L₀ · φ⁻ⁿ | θ(n) = β·(1−e^{−αn})
function generateRachis(L0, phi, beta, alpha, n_max):
  for n in range(0, n_max):
    barb_length = L0 * phi**(-n) // 황금비 감소
    angle = beta * (1 - exp(-alpha*n)) // 분기각 수렴
    drawBarb(x=rachis_x(n), y=rachis_y(n),
             length=barb_length, theta=angle)
  return feather_shape

// 결과: phi=1.618이면 타원형 깃털, phi=1.0이면 직사각형
② 감쇠 사인파 barb 곡률 알고리즘
// y(x) = A·sin(ωx)·e^{−γx}
function generateBarbCurve(A, omega, gamma, length):
  points = []
  for x in linspace(0, length, steps=200):
    y = A * sin(omega * x) * exp(-gamma * x)
    points.append((x, y))
  return points

// gamma 크면 → 앞쪽만 파동 → 올빼미 날개 소음저감 패턴
// gamma ≈ 0 → 균일 파동 → 수생조류 방수 패턴
③ 박막 간섭 색상 계산 알고리즘
// λ_peak = 2·n·d·cos(θ)
function structuralColor(n_refract, d_nm, theta_deg):
  theta_r = theta_deg * PI / 180
  lambda_peak = 2 * n_refract * d_nm * cos(theta_r)
  // nm → RGB 변환
  color = wavelengthToRGB(lambda_peak)
  return color

// d=80nm → 파랑(물총새) d=150nm → 초록(공작)
// d=200nm → 빨강(벌새) 모두 색소 없음
④ 프랙탈 차원 계산 알고리즘
// D = log(N) / log(1/r) — Box-counting method
function fractalDimension(feather_image):
  counts = {}
  for box_size in [2,4,8,16,32,64]:
    N = countNonEmptyBoxes(feather_image, box_size)
    counts[box_size] = N
  // 로그-로그 기울기 = 프랙탈 차원 D
  D = -slope(log(box_sizes), log(counts))
  return D // down feather ≈ 1.7, contour ≈ 1.3
⑤ 통합 파이프라인
// 수식 조건 → 패턴 생성 → 효과 예측 파이프라인
function featherPipeline(params):
  // STEP 1: 구조 생성
  shape = generateRachis(params.L0, params.phi, params.beta)
  curves = generateBarbCurve(params.A, params.omega, params.gamma)
  // STEP 2: 광학 특성
  color = structuralColor(params.n, params.d, params.theta)
  // STEP 3: 기계적 특성 예측
  D = fractalDimension(shape)
  noise_reduction = f(params.gamma, params.omega) // dB
  insulation = g(D) // W/mK
  adhesion_force = h(params.k, params.delta, params.alpha)
  return {shape, color, noise_reduction, insulation, adhesion_force}
